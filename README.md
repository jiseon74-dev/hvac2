# 산업환기 압력손실 계산기 (PWA)

덕트 재질별 표면조도와 덕트 길이를 반영해 원형 직관의 마찰 압력손실을 계산하는 설치형 웹앱입니다.

## 포함 파일

```text
industrial-ventilation-pressure-loss-pwa/
├── index.html
├── manifest.json
├── service-worker.js
├── README.md
├── .nojekyll
└── icons/
    ├── icon-192.png
    └── icon-512.png
```

## 주요 기능

- 탭 1: 덕트 풍속 + 덕트 직경 + 덕트 재질 + 덕트 길이
- 탭 2: 풍량 + 속도압 + 덕트 재질 + 덕트 길이
- 계산 과정별 레이놀즈수, 상대조도, 마찰손실계수, 속도압 표시
- 최종 직관 마찰 압력손실(Pa) 계산
- PWA 설치 및 서비스 워커 기반 오프라인 실행 지원

## 덕트 조도값

| 재질 | 절대조도 e (mm) |
|---|---:|
| 주물 강관 | 0.26 |
| 도금강관 | 0.15 |
| 흑피 강관 | 0.12 |
| 스테인리스 스틸 | 0.05 |
| PVC, Glass | 0.0015 |
| 플렉시블 덕트 | 0.7~1.2 (기본 1.2) |

## 계산식 및 기본 가정

- `Re = ρVD / μ`
- `e/D = 상대조도`
- `f = 0.0055 × {1 + [20,000(e/D) + 10⁶/Re]^(1/3)}`
- `VPd = ρV² / 2`
- `ΔP = f × (L/D) × VPd`

기본 공기 밀도 `ρ = 1.2 kg/m³`, 점성계수 `μ = 0.0000181 Pa·s`를 적용합니다.
마찰계수 식과 조도값은 사용자가 제공한 자료를 기준으로 구현했습니다.

## GitHub Pages 배포

1. GitHub에서 새 Public Repository를 만듭니다.
2. 이 ZIP을 압축 해제합니다.
3. 압축 해제한 폴더 안의 **파일과 `icons` 폴더 전체**를 저장소 최상위(root)에 업로드합니다.
4. Commit changes를 누릅니다.
5. 저장소의 **Settings → Pages**로 이동합니다.
6. Build and deployment에서 `Deploy from a branch`를 선택합니다.
7. Branch는 `main`, 폴더는 `/(root)`로 설정하고 Save를 누릅니다.
8. 배포가 완료되면 표시되는 `https://계정명.github.io/저장소명/` 주소를 공유합니다.

## 스마트폰 설치 및 오프라인 사용

- 배포 주소를 Chrome 등 브라우저에서 처음 한 번 온라인으로 엽니다.
- 페이지가 로드되고 서비스 워커가 캐시를 완료한 뒤 브라우저 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
- 이후 캐시된 앱 화면은 오프라인에서도 실행할 수 있습니다.
- 앱의 새 버전을 배포하면 온라인으로 다시 접속해 업데이트를 받아야 합니다.

## 계산 범위 및 주의사항

이 앱은 원형 직관의 마찰손실만 계산합니다. 엘보, 티, 댐퍼, 후드, 확대·축소부, 공기정화장치 등의 국부손실과 장치손실은 포함하지 않습니다. 실제 설계에서는 덕트의 실제 내경, 재질/제품 조도, 공기 온도 및 밀도, 제조사 자료와 현장 조건을 확인하세요. 계산 결과는 설계 검토를 위한 보조값입니다.
